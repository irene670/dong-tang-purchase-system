# 東瑭國際客戶採購系統

## 啟動

```bash
npm install
npm run dev
```

正式環境使用 Netlify Identity 驗證及 Netlify Database（Postgres）保存資料。帳號採邀請制，
管理員帳號需在 Netlify Identity 使用者設定加入 `admin` 角色。

## Google Sheets 串接

商品分頁使用原試算表的 `gid=1057262128`，訂單寫入 `工作表1`。

1. 將 `google-apps-script/Code.gs` 更新至該試算表的 Apps Script。
2. 重新部署 Web App，執行身分選擇擁有者。
3. `.env` 的 `VITE_GOOGLE_SCRIPT_URL` 已設定為目前部署網址。

`工作表1` 會接收：出貨核取方塊、訂單編號、廠商、聯絡人、訂購時間、商品明細、總金額、訂單狀態與出貨時間。

## 管理後台

- 使用 Netlify Identity 的 Email／密碼登入。
- 管理員必須具備 `admin` role；系統已移除共用的 `admin/admin` 密碼。
- 可編輯首頁主視覺、新品通知、活動、展示架說明及商品顯示內容。
- 首頁內容、商品覆寫、通路設定與訂單儲存在 Netlify Database。

## 常用採購

- 依登入公司分別保存歷史採購品項。
- 成功送出訂單後，自動累計採購次數與件數。
- 常用採購分類依歷史採購次數排序，方便通路快速重複下單。

## 既有庫存快速補貨

- 寄售通路在「常用採購」旁會看到「既有庫存」分類。
- 列出該通路曾有寄售庫存紀錄的商品，包含目前為 0 的缺貨品項。
- 商品依庫存水位由低至高排列，並可只看缺貨或 5 件以下的低庫存商品。
- 客戶可一邊查看目前庫存，一邊直接輸入補貨數量。

## 商品狀態標籤

- 支援「熱銷、新品、推薦、限量」四種標籤。
- 同一商品可同時套用多個狀態。
- 管理員可在後台商品管理中勾選或取消標籤。

## 通路折數

- 管理員可依通路公司名稱設定經銷折數，例如 `65%` 代表 `6.5 折`。
- 前台同時顯示零售價與該通路的經銷價，採購總額以經銷價計算。
- 可為個別通路勾選「不顯示經銷價」，前台只顯示零售價與採購件數。

## 寄售庫存

- 通路可設定為「買斷」或「寄售」，兩種模式分別設定折數。
- 寄售庫存公式：原庫存＋已出貨採購入庫－已確認銷貨數量±盤點修正。
- 後台包含寄售庫存總覽、銷貨單、盤點修正及完整異動紀錄。
- 銷貨單支援草稿、已確認、已請款與已作廢；確認扣庫、作廢自動回沖，並以來源單號防止重複扣庫。
- 客戶原始 PDF、圖片或 Excel 銷貨單由東瑭行政人員在管理後台上傳至 Google Drive 留存。

## 單據與進度中心

- 客戶可查看目前採購進度、歷史採購、歷史銷貨與寄售庫存。
- 銷貨紀錄同時保留客戶公司格式的原始銷貨單，以及東瑭正式銷貨單。
- 通路客戶前台為唯讀權限，只能檢視或下載單據，不能新增、修改或上傳。
- 後台支援匯入 `.xlsx` 正式銷貨單，先預覽及驗證，再批次確認並沖銷庫存。
- 標準欄位：`經銷商、銷貨月份、銷貨日期、SKU、商品名稱、售出數量、單價、備註`。
- 後台提供可直接下載的標準 Excel 範本。
